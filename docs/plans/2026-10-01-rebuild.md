## 全域約束與完成定義

- 已確認：Next.js + TypeScript、FastAPI + Python、單人學習版、Cloudflare 免費模型、ai-agent-lab。
- 應用與資料庫先本機執行；不做多使用者、計費、公開部署、替換舊部署或搬移原作者資料。
- 原系統功能是盤點來源；已批准省略獨立 SDK／Ollama 教學變體；其他去向依 D1，不得以重做之名默默省略。
- Will 已要求完成全部功能、中途不再詢問權限，並用 recording／design-review 記錄重要知識與決策。必要實作、免費依賴與本機驗收連續執行，不在步驟邊界停下；Docker 可協調暫停並恢复原狀。憑證只由 server 使用，不挪用其他身份憑證、不付費升級、本次依Will關session前要求提交功能與紀錄，不push。
- 完成：R01–R13 去向都有批准與驗收證據；B01–B06 有批准處置；前端 build／lint、後端 tests／lint、DB integration、browser E2E 通過；live 模型與外部工具有實測或清楚標成未驗證，不能宣稱完整完成。
- 測試策略：確定性接線用 fake provider 的 blocking tests；真模型品質用獨立 opt-in eval，避免免費額度與輸出變異使 CI flaky。

## 不變量

| 不變量 | 預計依賴模組 |
|---|---|
| 模型與工具只由後端呼叫 | apps/api/providers、tools、runtime；apps/web 的 API client |
| 每個 run 狀態與 history 隔離 | runtime、conversation repository、run service |
| terminal state 只轉一次，取消後不安排新副作用 | runtime、tool executor、SSE transport |
| 工具結果保留 tool_call_id，不能把失敗當成功或空結果 | provider adapter、tool registry、message assembler |
| 原問題、retrieval query 與文件 evidence 分開 | rag、chat service、report generator |
| 額度耗盡不能觸發付費 fallback | provider factory、error mapping、settings |
